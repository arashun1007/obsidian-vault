# 教材フォルダの使い方

購入した教材（Brainなど）をWeb Clipperで取り込んで、Claudeとの相談・業務改善に使うための置き場。

## 置き場所のルール

```
20_knowledge/教材/
  _教材フォルダの使い方.md   ← このファイル
  Brain/                    ← Web Clipperの「Brain教材」テンプレが自動保存する先
  （他のプラットフォームは増えたらフォルダを足す）
```

- クリップしたノートのファイル名は教材タイトルのまま（内容が主役のノート扱い）。
- 動画メインでクリップできない教材は、自分の言葉のメモを同じフォルダに置く。PDF配布ならPDFをそのまま置いてもよい（ClaudeはPDFも読める）。
- クリップ後、ノート末尾の「自分のメモ」を一言でも埋めると、あとでClaudeに相談するとき精度が上がる。

## 著作権のルール（重要）

- ここにあるのは**購入済み教材の私的な複製**。このvault（privateリポジトリ）の外に出さない。
- Claudeが教材を参照して助言するのはOK。ただし**教材本文を公開コンテンツ（Substack記事・GBP・チラシ等）へ転載・言い換え流用しない**。使えるのは「教材から学んで自分の実践に落とした結果」だけ。

## Claudeへの頼み方の例

- 「教材を踏まえて、GBP投稿の頻度を見直したい」
- 「◯◯（教材名）の要点を業務に当てはめると何が変わる？」
- 「教材の主張とうちの実データ（日報・記事メトリクス）を突き合わせて」
