# 初めてのタトゥー検討ログ

## 結論

- **モチーフ**: 石鯛(単体、装飾なし)
- **スタイル**: ブラックワーク、ウッドカット調
- **配置**: 左下腿側面、ふくらはぎ中央付近(タバコ箱サイズ)
- **彫師への伝え方**: 「ブラックワークでウッドカット調の石鯛」+ 姿勢は自然体(トロフィー的な硬いポーズではなく)、目に光の表現(候補: 瞳に白抜きの点/目の外側に短い放射線数本/同心円一重)
- **候補店**: blackeyestattoo溝の口(要事前確認: blackwork対応できる彫師がいるか)
- **意味**: 一水四見(魚にとって水は宮殿=魚と水は不可分)、荘子の「魚の楽しみ」、木魚(魚は瞼を閉じない=怠らず目覚めている)。彫師には言語化せず、内面に持っておく。

## 検討の経緯

きっかけは、ベルギーのアーティスト(raisedbysummer)の蟹のデザイン(タトゥー参考画像、tattoo token購入制)。ブラックワーク+白抜き文様、波と太陽のデフォルメが魅力的だった。

候補として、蟹 / 石鯛(ブラック&グレイのリアル) / タコ・海亀・シュモクザメ・ハコフグ(象徴生物)を比較。

- **優先順位**: 体験・アイデンティティ > 抽象的な象徴。厳つい印象は避けたい、お洒落で可愛い方が良い。
- **タコ・シュモクザメ**: 却下(タコは手垢がつきすぎ、シュモクザメは可愛くない=希望条件と逆行)
- **ハコフグ**: 造形は最有力候補だったが、可愛すぎるという理由で却下
- **蟹 vs 石鯛の比較**:
  - 蟹はすでに完成したデザインがある安心感、フォルムの面白さ、波・太陽のデフォルメの魅力。ただし見ず知らずのアーティストの既製デザインで、ナラティブとしての自分ごと感が弱い(token購入して忠実再現 vs イメージだけ見せてオリジナル、の判断も発生)
  - 石鯛はスピアフィッシャーとしての体験に直結するが、当初は「日本中で誰もが目指す定番魚」という先入観があった(→ 実際にはネット上にも参考画像がなく、この前提は誤りだったと訂正)
- **生物の意味の比較**(クラゲの脱力感、鯨の神秘性との対比から展開):
  - 蟹 = 硬い甲羅+柔らかい中身、横歩き、脱皮 →「守る・したたかに適応する・再生」という現実的な意味
  - 魚 = 荘子の魚の楽しみ、水を得た魚のよう、木魚(目覚め)、一水四見(魚にとって水は宮殿) →「水と一体である・怠らず目覚めている」という道教・禅的な意味。個人的に惹かれる思想(仏教・道教・禅)と直結
  - 蟹は潮間帯(陸と海の境界)の生き物であり、完全に水の中で完結する魚ほど「海そのもの」を体現しない、という違いも決め手になった
- **蟹への未練**: デザインの完成度・フォルムの面白さ・波と太陽のデフォルメ。ただし語る言葉が「鑑賞者としての評価」であり、魚について語るときの「愛着」とは温度差があった
- **統合案**(検討したが不採用): 蟹のデザイン言語(波・太陽・文様)を石鯛に移植する案 → 「魚そのものが意味を持っている」という結論に達し、装飾なしのシンプルな石鯛単体に着地。波や太陽を足すと「魚と水は不可分」という一水四見の意味とかえって矛盾する(魚と水を別パーツとして分離してしまうため)、という理由も後押しした
