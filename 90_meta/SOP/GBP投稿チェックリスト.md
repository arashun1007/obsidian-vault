# GBP投稿・施工事例 公開前チェックリスト

/work-content が作った下書きを公開する前に、必ず人間がこれを通す。
**1つでも引っかかったら公開しない。**

## 個人情報（最重要）
- [ ] お客様の氏名が入っていないか（「〇〇様邸」も不可。「川崎市◯◯区のお客様」まで）
- [ ] 番地・建物名など、家が特定できる情報が入っていないか
- [ ] 写真に表札・車のナンバー・顔・隣家の窓が写り込んでいないか
- [ ] 施工事例・写真の掲載について、お客様の了承を得たか

## 内容
- [ ] 実際にやった作業・起きた変化だけを書いているか（誇張なし）
- [ ] 「絶対」「必ず」「地域No.1」等の断定・優良誤認になりうる表現がないか
- [ ] 料金を載せる場合、条件（樹種・本数・処分量）を添えたか。載せない判断もあり
- [ ] ハチ駆除など資格・条件が関わる作業について、誤解を招く書き方をしていないか

## 形式
- [ ] 地域キーワードが自然な文になっているか（羅列は逆効果）
- [ ] Before/After写真の順序・向きは正しいか

## 投稿後
- [ ] 下書きファイルの冒頭に「公開済 YYYY-MM-DD」と追記
