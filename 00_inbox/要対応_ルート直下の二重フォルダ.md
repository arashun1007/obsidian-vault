# 要対応: ルート直下の二重フォルダ構造

出典: 2026-08-12、日記テンプレのリンク切れ調査中に発覚。

## 問題

CLAUDE.mdが定めた正式構造(`00_inbox`〜`90_meta`)と並んで、ルート直下に同じ役割の古いフォルダが二重に存在している。実際にアプリ側の設定(Templaterのテンプレートパスなど)が、正式構造ではなく**古い方**を向いていることが今回わかった(`テンプレ/日記テンプレ.md`が実際に使われていて、`90_meta/テンプレ/日記テンプレ.md`は使われていなかった)。

対応済み: `work` → `10_work/日報`（本日統合済み）、日記テンプレの日報リンク（新旧両方のテンプレファイルを修正）。

## 未対応・重複が疑われるフォルダ

| ルート直下(古い・実際に使われている可能性) | 正式構造の対応先 |
|---|---|
| `テンプレ` | `90_meta/テンプレ` |
| `仏教`・`内省`・`読書ノート`・`概念宇宙` | `20_knowledge/仏教` など |
| `Clippings` | 不明・要確認 |
| `Substack` | `30_publish/Substack` |
| `counseling` | `10_work/counseling` |
| `inbox` | `00_inbox` |
| `agent-skills` | `20_knowledge/agent-skills` |
| `secondbrain`・`note`・`Pictures to documents` | 不明・要確認 |

## やるべきこと

1. 各ペアについて、どちらが実際にアプリの設定(テンプレートパス、プラグイン設定等)から参照されているかを確認する
2. 実際に使われている方を正、もう片方を統合・削除する(work/10_work日報と同じ要領)
3. 統合後、CLAUDE.mdのフォルダ構造の説明を実態に合わせて更新する
4. 各skill(essay-draft, work-content等)が参照しているパスも、統合後のパスと一致しているか確認する

急ぎではないが、今夜見つかったテンプレートリンク切れのような不具合が、他の場所でも起きている可能性がある。次に「なぜか反映されない」系の不具合が出たら、まずここを疑う。
