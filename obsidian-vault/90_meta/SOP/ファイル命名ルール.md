# ファイル命名・保存ルール

迷ったらここに従う。ルールは「後から検索できること」だけを目的にする。

## 日付が主役のノート

| 種類 | 置き場所 | ファイル名 |
|---|---|---|
| 日記 | `01_daily/YYYY/MM/` | `YYYY-MM-DD.md` |
| 作業日報 | `10_work/日報/YYYY/MM/` | `YYYY-MM-DD_work.md` |
| 営業コンテンツ下書き | `10_work/営業コンテンツ/` | `YYYY-MM-DD_作業種別.md`（例: `2026-07-07_剪定.md`） |
| 週次レビュー | `01_daily/weekly/` | `YYYY-Www_レビュー.md`（例: `2026-W28_レビュー.md`） |
| カウンセリングログ | `01_daily/counseling/` | `カウンセリング_YYYY_MM_DD.md` |
| 魚突きノート | `20_knowledge/魚突き/` | `YYYY-MM-DD_場所.md` |

## 内容が主役のノート

| 種類 | 置き場所 | ファイル名 |
|---|---|---|
| 記事素材シート | `30_publish/Substack/素材/` | `YYYY-MM-DD_ひとこと.md`（例: `2026-07-07_魚の胃袋.md`） |
| 記事下書き〜完成 | `30_publish/Substack/記事/` | `ひとことタイトル.md`（公開後、冒頭に公開日を追記） |
| ナレッジ | `20_knowledge/` | 内容がわかる名詞（`概念宇宙/◯◯.md`） |
| 未分類 | `00_inbox/` | 何でもよい（週次で振り分けて空にする） |

## 原則

1. 日付は必ず `YYYY-MM-DD`（ハイフン区切り）。検索とソートのため。
2. `Untitled.md` を残さない。inboxに置くのは構わないが、週次レビューで必ず名前を付けるか捨てる。
3. 添付画像は `90_meta/attachments/` に自動保存（Obsidian設定）。手動で動かさない。
4. 1ファイル1トピック。長くなったら分割。
5. 削除は `.trash/` 経由（Obsidianのゴミ箱設定）。Claudeにはファイル削除をさせない。
