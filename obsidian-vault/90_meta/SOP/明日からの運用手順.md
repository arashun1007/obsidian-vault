# 明日からの運用手順

全部やろうとしない。◎だけで回る。◯は余裕がある日だけ。

## 毎日（合計15〜20分＋執筆）

### 朝イチ or 現場の合間（スマホ、2分）
- ◎ 気づいたことを `00_inbox/` かデイリーノートの「発信ネタ」欄に一行メモ。
  写真を撮る（Before/After、観察対象）。

### 仕事終わり（5分）
- ◎ 日報を書く（`Template_work` テンプレ）。全部埋めない。「AI生成用メモ」欄だけは一言書く。
- ◯ 営業に使えそうな現場なら、Claudeに「今日の日報から営業コンテンツ作って」（/work-content）。
  → 下書きができるので、`GBP投稿チェックリスト` を通してから自分で投稿。

### 夜（執筆、20〜30分）
1. ◎ 日記テンプレで今日の日記（発信ネタ欄まで）。
2. ◎ 書く日: 素材をClaudeに渡して「記事にしたい」（/essay-draft）→ 足場をもらう → **本文は自分で書く**（20〜30分、800字目安、良い一文が1つあれば勝ち）。
3. ◎ 書けたらClaudeに「推敲して」（/essay-edit）→ 直す → `Substack投稿前チェックリスト` → 投稿。
4. ◎ 投稿したら `記事メトリクス.csv` に1行追記。
5. 書けない日: Claudeに「今日は調子が悪い。逃げネタから提案して」と言う。

## 毎週（日曜など、15分）
- ◎ Claudeに「週次レビューして」（/weekly-review）。
  → 日記から記事のタネを拾い、ネタストック補充案が出る。承認したものだけ追記してもらう。
- ◯ `00_inbox/` を空にする（命名ルールに従って振り分け）。

## 毎月（月末、10分）
- ◯ 記事メトリクス.csv を見ながらClaudeに「今月の反応傾向を分析して」。
- ◯ 日報から「今月の作業種別・件数・売上」を集計してもらう。

## Claudeの開き方
- スマホ/PCの Claude（claude.ai）→ Claude Code でこのリポジトリ（obsidian-vault）を開く。
- vaultを開けば CLAUDE.md とスキルが自動で読み込まれる。
- スマホのObsidianだけで完結したい日は、`30_publish/Substack/プロンプト/` のコピペ用プロンプトを使う。

## 守ること
- 投稿・送信ボタンは常に人間が押す。
- 既存ノートをClaudeに書き換えさせるときは、対象ファイル名を明示して指示する。
- 日記・カウンセリングログの分析は、自分から頼んだときだけ。
