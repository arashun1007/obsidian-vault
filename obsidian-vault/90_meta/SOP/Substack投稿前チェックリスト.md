# Substack投稿前チェックリスト

投稿ボタンを押す前に、90秒でこれだけ確認する。完璧を目指さない（100点を求めず等身大で送り出す方針）。

## 中身
- [ ] 冒頭は「今この瞬間」から始まっているか（背景説明から入っていないか）
- [ ] 1記事の核は一点だけか（2つ以上入っていたら明日の記事に回す）
- [ ] 読者に渡せる問いが入っているか
- [ ] 結びは宣言・教訓ではなく観察で終わっているか
- [ ] ビジネス自己啓発語（自己効力感・報酬・3日坊主 等）が混ざっていないか

## 安全
- [ ] 家族・お客様・知人が特定できる記述がないか
- [ ] 職場・現場が特定できる写真や地名の細かすぎる記述がないか
- [ ] 内省の暗さが前面に出すぎていないか（内省は奥に沈める）

## 形式
- [ ] タイトルは身体性のある動詞で終わっているか（推奨であって義務ではない）
- [ ] スマホでプレビューして改行・余白を確認したか
- [ ] 誤変換チェックをしたか（Claudeに「誤変換だけ見て」と頼むのが早い）

## 投稿後（30秒）
- [ ] `30_publish/Substack/記事メトリクス.csv` に1行追記（日付・タイトル・種別・テーマ分類）
