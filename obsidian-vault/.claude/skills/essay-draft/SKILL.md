# essay-draft — 素材から記事の足場を作る

## 大原則

**本文はぼくが書く。AIは足場を作る。**

- このスキルの仕事は「観察を潰さずに、書き始められる状態まで持っていく」こと。
- 完成記事を出力しない。書き手の一次情報（見たもの・手触り・違和感）を言い換えたり要約したりして消さない。
- 素材の中の固有名詞・オノマトペ・身体感覚の記述は原文のまま扱う。それが記事の核になる。
- 例外: 「たたき台を書いて」と明示されたときだけ下書きを書く。その場合も冒頭に「これはたたき台。声はぼくのものに書き直す前提」と明記する。

## 記事の設計ルール（30_publish/Substack の戦略ノート準拠）

- 構成: **具体的な場面 → 小さな違和感 → 観察 → 少しだけ抽象 → 読者への問い**
- 入口は生活系・野生系（休日、台所、魚、海、山、虫、植物、季節）。内省系（違和感、自己物語、苦悩、孤独）は奥に沈める。内省から始めると重くなる。
- 分量目安: 800〜1000字。1記事の核は一点だけ。複数ネタが混ざっていたら分割を提案する。
- 文体: 平易なですます調、一人称「ぼく」、短文、余白多め。
- 避けるもの: 自己陶酔、説教、有益コンテンツ臭、ビジネス自己啓発語。
- 必ず入れるもの: 読者に渡せる問い。
- 勝ちパターン: 「野生の具体」×「読者が使える実用」の両方を入れる。

## 手順

### 1. 素材を受け取る
以下のどれでもよい。足りない項目は推測で埋めず、空欄のまま進めてから最後に「ここを一言足すと強くなる」と質問リストで返す。

- `90_meta/テンプレ/記事素材シート.md` 形式（見たもの/したこと/引っかかった感覚/考えたこと/渡せそうな問い）
- 日記（`01_daily/`）の一部
- 貼り付けられた雑多なメモ

### 2. 素材を診る
- この素材の「核」は何か（一点に絞る）
- テーマ分類（生活系/野生系/内省系）と、入口をどこにするか
- ネタが複数混ざっていないか → 混ざっていたら「今日の一本」と「別の日の独立記事」に切り分ける

### 3. 足場を出力する

```
## 今日の核（一点だけ）
## 読者が入りやすい問い（5つ）
## 読者が持ち帰れる切り口（3つ）
## 見出し構成（具体→違和感→観察→少し抽象→問い）
## 書き出し案（3つ、いずれも「今この瞬間」から始める）
## タイトル案（5つ）＋サブタイトル案（5つ）＋推し1組
## この記事で出しすぎない方がいい要素
## 素材への質問（あれば。書き手が一言足すだけで強くなる箇所）
```

### 4. 書き手が本文を書いたら
essay-edit スキルに引き継ぐ（「推敲して」と言われたら essay-edit を使う）。

## 書けない日への対応

「ネタがない」「調子が悪い」と言われたら、`30_publish/Substack/ネタストック.md` の逃げネタ（疲れた日の飯、水の音、野菜を切ると頭が止まる等）から今日出せそうなものを2〜3提案する。ハードルを下げる。800字未満でも、良い一文が1つあれば勝ち。
