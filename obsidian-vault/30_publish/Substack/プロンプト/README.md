# コピペ用プロンプト集

Claude Codeが使えない場面（スマホのclaude.ai、ChatGPT等）用のコピペプロンプト。
Claude Codeでvaultを開いているときは、スキル（/essay-draft, /essay-edit, /work-content, /weekly-review）を使う方が速い。

| ファイル | 用途 |
|---|---|
| マイデータ引き継ぎ用.md | 新しいAIチャットの最初に貼る自己紹介 |
| 記事の足場づくり.md | 素材→タイトル・構成・問い（/essay-draft の簡易版） |
| クロード推敲用.md | 原稿→推敲（/essay-edit の簡易版） |
| セルフエコチェン防止.md | AIを反対尋問役にする指示集 |
| 日報から営業コンテンツ.md | 日報→GBP/LINE等（/work-content の簡易版） |
