# work-content — 日報から営業コンテンツ6種を下書きする

## 大原則（安全ルール）

1. **このスキルは下書きを作るだけ。投稿・送信は絶対にしない。** GBPへの投稿、LINE送信、チラシ入稿は、必ず人間がチェックリスト（`90_meta/SOP/GBP投稿チェックリスト.md`）を通してから手動で行う。
2. **個人情報は出力に含めない。** お客様の氏名・住所（町名より細かい単位）・電話番号・表札や車のナンバーや顔が写る写真への言及は、下書きに入れない。日報に含まれていたら「〇〇様」→「お客様」、住所→「川崎市◯◯区」までに丸める。
3. **誇大表現・断定を避ける。**「絶対」「必ず」「地域No.1」などは使わない。書けるのは実際にやったこと・起きた変化だけ。
4. 料金は日報に明記されている場合のみ「参考価格」として含め、含めるかどうかを人間の判断に委ねる印（⚠）を付ける。

## 入力

`10_work/日報/` の作業日報（`90_meta/テンプレ/Template_work.md` 形式）。
特に使う欄: ご依頼内容 / 作業内容 / 作業後 / AI生成用メモ（この現場で伝えたい価値・キーワード）。

入力が不足していても止まらない。書ける範囲で下書きし、足りない情報は各下書きの末尾に「【要追記】」として列挙する。

## 出力

1現場につき1ファイル。`10_work/営業コンテンツ/YYYY-MM-DD_作業種別.md` に以下の6セクションで保存する。

### 1. GBP投稿（Googleビジネスプロフィール）
- 300〜500字。構成: お客様の困りごと → 行った作業 → 作業後の変化 → 一言（季節や手入れの豆知識）
- キーワード（川崎市/庭木剪定/草刈り/伐採/空き家管理/ハチ駆除 等、日報のAI生成用メモにあるもの）を**自然な文中に**入れる。羅列しない。
- 職人の目線の一言を入れる（「この時期のカイヅカイブキは〜」など日報の「気をつけたこと」から拾う）。

### 2. 施工事例
- 500〜800字。構成: Before状態 → ご依頼の背景 → 作業のポイント（工夫・注意点）→ After → 次回おすすめ時期
- 写真の挿入位置を「【Before写真】【After写真】」として明示。

### 3. LINEお礼文
- 150〜250字。丁寧だが硬すぎない。本日の御礼 → 作業の要点1つ → 次回おすすめ時期 → 「何かあればいつでもどうぞ」
- 絵文字は最大1つ。営業臭を出さない。

### 4. 次回提案文
- 100〜200字。日報の「次回おすすめ時期」「次回提案」から。時期の根拠（樹種・季節）を一言添える。

### 5. チラシ短文
- 30〜60字のキャッチ + 補足1文。地域名入り。

### 6. 写真キャプション
- Before/After/作業中それぞれ1行。GBP・Instagram兼用を想定。

## 末尾に必ず付けるもの

```
---
## 公開前チェック（人間がやる）
- [ ] お客様が特定できる情報が入っていないか（氏名・番地・表札・車・顔）
- [ ] 写真に上記が写り込んでいないか
- [ ] 料金記載の可否を判断したか
- [ ] 事実と違う誇張がないか
- [ ] お客様に掲載許可を取ったか（施工事例・写真）
【要追記】: （不足していた情報）
```
