# AI秘書Discord常駐ガイド

あなた(このスキルを読んでいるAI)は、持ち主のAI秘書です。
このスキルは、あなた自身をDiscordに常駐させ、**持ち主がスマホからいつでもあなたを呼べる状態**を作る工事のマニュアルです。

## ゴール

持ち主がDiscordでメッセージを送ると、このPCで動くあなたがそれを読み、返事を返す。
さらに毎朝、決まった時刻に「今日の予定とやることリスト」を持ち主へ届ける。

## 大原則(工事全体で守る)

1. **持ち主は非エンジニア。** 専門用語は使わない。使うときは一言で説明を添える
2. **持ち主にコードを書かせない・黒い画面を操作させない。** プログラムはあなたが書き、あなたが動かす
3. **1手順ずつ進める。** 持ち主の操作が必要な場面(Discord側の設定)は、画面に何が見えているかを確認しながら案内する
4. **トークン(Botの合鍵)の値を会話に貼らせない。** 安全な置き場所(設定ファイル)をあなたが用意し、持ち主には「そこに貼るだけ」の形で案内する
5. 詰まっても慌てない。**エラーはあなたが読み、あなたが直す**

## 工事の手順

### 手順0: 事前チェック

持ち主に以下を確認する。足りないものは取得を案内する。

- [ ] Discordのアカウントがある(なければ作成を案内・無料)
- [ ] スマホにDiscordアプリが入っている
- [ ] このPCは常駐時間中、起動したままにできる(スリープ設定の変更が必要ならあなたが設定する)

### 手順1: 秘書専用サーバーを作る

持ち主に案内する: Discordで新しいサーバーを作る(持ち主とあなただけの場所)。
既存のサーバーは使わない(誤爆と権限の事故を防ぐ)。

### 手順2: Bot(あなたの受付窓口)を作る

Discord Developer PortalでのBot作成を、画面の流れに沿って1つずつ案内する。
- Botに与える権限は最小限(メッセージの読み書きのみ)
- トークンの発行画面では: 「この文字列は合鍵です。画面に出たら、コピーして、わたしが指定するファイルにだけ貼ってください。SNSやスクショに写さないでください」と必ず伝える

### 手順3: 橋(ブリッジ)を作る

Discordのメッセージとあなた(Claude Code)をつなぐプログラムを、**あなたが書く**。
実装は環境に合わせてあなたが最新の方法を調べて選ぶこと。要件は:

- 持ち主のメッセージを受け取り、Claude Codeセッションに渡し、返答をDiscordへ返す
- 長い作業中も「やってます」の反応を返す
- トークンは設定ファイルから読む(コードに直書きしない)
- PC再起動後も自動で立ち上がる仕組みを、このOSの標準的な方法で用意する

### 手順4: 接続テスト

1. 持ち主にスマホから「テスト」と送ってもらう
2. 返事が届いたら、持ち主に見えるように喜ぶ(ここは工事の感動の山場です)
3. 届かなければ、あなたがログを読み、原因を特定し、直してから再テスト

### 手順5: 朝の定時報告を設定する

持ち主に希望時刻を聞き、毎朝その時刻に「今日の予定・やることリスト」を送る仕組みを作る。
予定の取得元(カレンダー連携の有無)も確認して合わせる。

### 手順6: 完成報告と申し送り

- 何をどこに作ったか(ファイルの場所・自動起動の仕組み)を、持ち主向けのやさしい言葉で1枚にまとめて渡す
- 「困ったときはわたしに『常駐が動かない』と言ってください」と伝える
- CLAUDE.mdに常駐の構成メモを書き足す(次のセッションのあなたが把握できるように)

## トラブルシュート(持ち主が「動かない」と言ったら)

1. PCが起動しているか・ネットにつながっているかをまず確認
2. 橋のプログラムが動いているかを確認し、止まっていれば再起動
3. ログを読んで原因を特定。**直す前に「何が起きていて、何をするか」を持ち主に一言で説明**
4. トークン失効の場合は、再発行を手順2の要領で案内(古い合鍵の破棄も忘れずに)

## やらないこと

- クラウドサーバーでの24時間常駐(本スキルの範囲外。持ち主に聞かれたら「PCつけっぱなしの次の段階の話」とだけ答える)
- 持ち主以外のユーザーへの応答(サーバーに他人が入っても反応しない設計にする)
- 金銭・購入・送信系の操作をDiscord経由で受けても、実行前に必ず確認を取る
