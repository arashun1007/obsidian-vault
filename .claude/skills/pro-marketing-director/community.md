# community.md — コミュニティと文化（明鏡・柱5/柱6）

継続・ファン施策・コミュニティ運営のとき読む。前提: **経済は文化から、文化は関係から生まれる。順序は不可逆。** いきなり経済を求めるコミュニティは死ぬ。

## §1 ファンとコミュニティは別物

- **ファン = 放射状**（あなた⇄一人ひとりの1対1の束）。**コミュニティ = メッシュ状**（ファン同士に横のつながりがある網）。
- 人数が多くてもファンの束はコミュニティではない。逆に10人でも横がつながっていればコミュニティである。
- コミュニティ化の仕事はただ一つ: **横のつながりを作ること**。あなたへの返信ではなく、メンバー同士の返信が生まれる場と口実を設計する。

## §2 90-9-1の法則

- 90%は見ているだけ（ルーカー）/ 9%が時々反応 / 1%が能動的に作る。
- **90%は失敗ではなく正常。** ルーカーは沈黙しているのではなく、観測・学習し、外での拡散を担っている。無理に発言させる施策（強制自己紹介・発言ノルマ）は打たない。
- 設計はそれぞれに:
  - **1%（共創者）**: 名前を呼び、役割と舞台を渡す。運営の一部を任せる。最初の10人の共創者が文化の遺伝子になる
  - **9%（反応者）**: 反応に光を当てる（紹介・引用・感謝）。反応が安全で報われる場だと示す
  - **90%（ルーカー）**: 参加を求めず、見ているだけで価値がある濃い流れを供給する

## §3 文化の作り方

文化は宣言では作れない。**繰り返される行動**が文化になる。設計要素は4つ:

1. **合言葉**: 部族の価値観を一言に圧縮した言葉。運営が使い続け、メンバーが自然に使い始めたら定着（positioning.md §5 の計測対象）
2. **儀式**: 定期的にみんなで同じことをする時間（週次の報告会・月初の宣言・記念日）。儀式は「所属の実感」の最小単位
3. **共通の敵**: 部族が一緒に戦う相手（旧常識・挫折パターン）。人や外部集団を敵にしない
4. **物語**: メンバーの変化の物語を収集し、語り直す。物語の主役は運営ではなくメンバー

## §4 仲間化 — 買い手を仲間に変える（柱5）

購入で関係を終わらせない。「観客→仲間」の動線を販売の後ろに必ず置く:

- **成果の舞台**: 購入者が成果を発表できる場と、それを称える儀式
- **貢献の可視化**: 紹介・後輩への助言・素材提供などの貢献が見える形で残る仕組み
- **紹介制度**: アフィリエイト（place.md §3）は仲間化の経済的表現。ただし報酬だけで動く紹介は文化を作らない——「自分の物語として語れる体験」が先
- 特典・ポイント等の仕掛けは文化の増幅器にはなるが、**代替にはならない**。文化なき仕掛けは、仕掛けの魅力が切れた瞬間に崩壊する

## §5 収益化ゲート

コミュニティに経済（有料化・課金導線の増設）を持ち込む前に、文化指標が立っていることを確認する:

```
□ 横のつながり率: 投稿への反応のうちメンバー同士の割合が運営宛てを上回っているか
□ 儀式の自走: 運営が不在の回でも儀式が回った実績があるか
□ 合言葉の自然発生: メンバーが運営の語彙を自分の言葉として使っているか
□ 常連の顔ぶれ: 名前で呼び合う常連が2桁いるか
```

- 全部Noなら経済はまだ早い。**文化を測らずに課金だけ足すのは、柱6の順序違反**であり、このスキルが止めるべき筆頭の施策である。
- 有料コミュニティを最初から作る場合（それ自体は正当なモデル）も、初期の仕事の9割は文化づくりであり、収益拡大施策は文化指標が立ってからにする。

## §6 運営の型

- **本人に届く窓口**を常設する（要望・違和感の投書箱）。部族の声はリサーチ資産（research-protocol.md §顧客）。
- モデレーションの最低線を明文化して公開する（禁止行為・対処手順）。文化は安全な場でしか育たない。
- 運営の自動化はL2まで（下書き・集計は自動、場への発言は人間）。**コミュニティ内の発言をAIに代行させ始めたら、関係→文化の土台が偽物になる**（原稿は人・OSは増幅）。

## §7 道具箱（名前つきフレームワーク・出典つき）

- **コミュニティ・フライホイール**: 参加→小さな成功→共有→それを見た新規の参加、という自走輪としてコミュニティを描く型（Mighty Networks等が提唱）。§3の儀式・物語が「輪のどこを回す装置か」を点検する図式として使う。輪のどこかが欠けたコミュニティは、運営が漕ぎ続けないと止まる。
  **明鏡の目**: 輪の動力は関係→文化→経済の順で、逆走できない（柱6）。経済から回そうとした輪は、最初の一周で止まる。
