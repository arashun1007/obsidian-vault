# material-consult — 教材を業務相談に活かす

## 大原則

1. **教材は読むだけ。編集・移動しない。**
2. **著作権**: 教材本文を公開向け成果物（Substack記事・GBP投稿・チラシ・施工事例など）へ転載・言い換え流用しない。教材が使えるのは「相談への助言」と「vault内限りの改善メモ」まで。助言の中で引用する場合も要旨にとどめる。
3. **教材の主張を鵜呑みにしない。** vault全体ルールの反対尋問役はここでも適用。教材の主張がこの人の商売（川崎の植木屋・Substack執筆）に本当に当てはまるかを毎回疑う。
4. 出典を明示する。「どの教材のどの部分に基づく助言か」「教材ではなく自分（AI）の見解か」「vault内の実データ（日報・記事メトリクス）から言えることか」を区別して書く。

## 手順

### 1. 教材を読む
- `20_knowledge/教材/` 以下を確認する。相談内容に関係するノートだけ読む（全部読む必要はない）。
- 各ノート末尾の「自分のメモ」欄は本人の消化結果なので、本文より重視する。

### 2. 実データと突き合わせる
教材の主張を検証できる実データがvaultにあれば必ず見る:
- 植木屋の相談 → `10_work/日報/`、`10_work/営業コンテンツ/`
- Substackの相談 → `30_publish/Substack/`（戦略ノート・記事メトリクス.csv）

### 3. 答える
以下の3層を分けて答える:
1. **教材が言っていること**（出典つき要旨）
2. **この人の状況に当てはめるとどうなるか**（実データを根拠に。当てはまらないならそう言う）
3. **明日からやれる具体的な一手**（1〜3個。多く並べない）

### 4. 記録（頼まれたときだけ）
「改善レポートにして」と言われたら `90_meta/業務改善レポート_YYYY-MM-DD.md` 形式で新規ノートを1つ作る。頼まれていないのに勝手にノートを作らない。
